プライバシーポリシー

制定日：2026年11月8日　／　最終改定日：2026年11月8日

U2企画合同会社（以下「当社」）は、当社のウェブサイトおよび当社が提供するソフトウェア・機器・サービス（以下総称して「本サービス」）において取り扱う個人情報および利用者情報を、個人情報の保護に関する法律その他の関係法令等に従って適切に取り扱います。本ポリシーは、当社がどのような情報を、どのような目的で取得し、どのように利用・保管・提供し、利用者がどのように関与できるかを定めるものです。

1.適用範囲

本ポリシーは、次の各号に掲げる場面における個人情報および利用者情報の取扱いに適用されます。

  1. 当社ウェブサイト（www.u2kikaku.com）の閲覧およびお問い合わせ
  2. 当社が提供する遠隔ライブ配信ソリューション（配信監視プログラム YTLiveWD を含みます）
  3. 当社が提供するスナップショット自動投稿プログラム Camera Auto Tweet およびこれに付随する設定用ウェブ画面
  4. 当社が提供する環境モニタリングシステム（気象・積雪センサー、通信ゲートウェイ機器およびそのファームウェア、ならびに測定データの配信基盤を含みます）
  5. 当社が本サービスに関して行う見積、設計、設置、保守、遠隔サポートその他の付随業務

本サービスには、利用者（法人その他の団体である場合はその従業者を含みます）の設備、アカウントおよびネットワークが関与します。当社が利用者から委託を受けて取り扱う情報のうち、その取扱いの目的および方法を利用者が定めるものについては、第5項の定めによります。

4.利用目的

当社は、取得した個人情報を次の目的の範囲内で利用します。目的の範囲を超えて利用する必要が生じた場合は、あらかじめ本人の同意を得るものとします。

  1. お問い合わせ、ご相談、見積および技術的検証（PoC）のご依頼への対応
  2. 本サービスの設計、構築、設置、設定、保守および障害対応
  3. ご契約の締結・履行、請求およびお支払いの管理
  4. 本サービスの品質向上、不具合の原因調査および再発防止
  5. 本サービスに関する重要なお知らせ（仕様変更、外部APIの変更、保守作業等）の連絡
  6. 法令等に基づく対応

当社は、要配慮個人情報（人種、信条、病歴等）を取得しません。また、取得した個人情報を、本人の同意なく第三者に販売または提供することはありません。

5.委託に基づく取扱い（カメラ映像・測定データ等）

本サービスにおけるカメラ映像・スナップショット、ゲートウェイが収集する測定データ、およびこれらに付随するログについて、その取扱いの目的および方法を定めるのは利用者（設置場所の管理者）です。当社は、利用者から委託を受けた範囲内でこれらの情報を取り扱い、委託の目的の範囲を超えて利用せず、自らの用途に二次利用しません。

当社が委託に基づき情報を取り扱う場合、当社は個人情報の保護に関する法律第25条に基づき、委託先の選定、委託契約における取扱条件の明確化、および必要かつ適切な監督を行います。

カメラ映像には、通行人、来訪者、従業者その他の第三者が映り込む場合があります。当該映像の撮影、保存、掲載および公表に関する権利処理、撮影場所における告知・掲示、肖像権・プライバシーへの配慮は、設置者である利用者の責任において行われるものとします。当社は、利用者に対し、撮影範囲および公表範囲を必要最小限にとどめる設定を推奨します。

8.安全管理措置

当社は、個人データの漏えい、滅失またはき損の防止その他の安全管理のために、次の措置を講じます。

  • 組織的措置：個人情報の取扱責任者を定め、取扱方法および報告連絡体制を整備します。
  • 人的措置：取扱者を必要最小限の範囲に限定し、秘密保持に関する義務を課します。
  • 物理的措置：個人情報を含む機器および記録媒体の持ち出し、保管および廃棄の方法を定めます。
  • 技術的措置：認証情報を権限を限定したファイルとして保存し、通信の暗号化（TLS）、アクセス制御、機器のファームウェア更新その他の対策を講じます。
  • 委託先の監督：委託先における取扱状況を必要かつ適切な方法により確認します。

本サービスのうち、利用者の設備上で稼働するもの（Camera Auto Tweet、YTLiveWD、ゲートウェイ機器等）については、認証情報およびデータの保管場所が利用者の管理下に置かれます。当該機器へのアクセス制御、ネットワークの保護、バックアップおよび不要になったデータの削除は、利用者の責任において行われるものとします。

9.保有期間および削除

  • お問い合わせ情報：対応の完了後、合理的な期間（目安として1年）を経過した後に削除します。ただし、ご契約に関する情報は、法令に定める保存期間および会計処理上必要な期間、保存します。
  • スナップショット画像：利用者の設備内に保存され、当該設備の設定に従い、新しい画像の取得に伴って古いものから自動的に削除されます（初期設定では最新100件を保持）。
  • 実行履歴・ログ：利用者の設備内に保存され、利用者が削除するまで保持されます。
  • 外部サービス連携情報：利用者が連携を解除し、または認証情報を変更するまで保持されます。
  • 測定データ：利用者が指定する配信先における保存期間に従います。

10.開示・訂正・利用停止等の請求

本人は、当社が保有する自己の保有個人データについて、利用目的の通知、開示、内容の訂正・追加・削除、利用の停止・消去、第三者への提供の停止、および第三者提供記録の開示を請求することができます。ご請求は第13項の窓口までご連絡ください。

ご請求の際は、ご本人であることを確認させていただくため、運転免許証、健康保険被保険者証その他の公的書類の写しのご提出をお願いする場合があります。なお、委託に基づき利用者の設備内に保存されている情報（カメラ映像、実行履歴等）については当社では保有していないため、設置者である利用者へご請求ください。

ご請求を受領した日から原則として2週間以内に、書面または電磁的方法により回答します。法令に基づき開示しない旨の決定をした場合は、その旨および理由を通知します。

11.本サービスにおけるXおよびYouTube APIの利用

本サービスは、X APIおよびYouTube API Servicesを利用します。これに伴い、次の事項をお知らせします。

  • 本サービスは、機能の提供のためにYouTube API Servicesを利用しています。
  • 本サービスによるGoogleの情報の利用は、Google プライバシーポリシーに従います。YouTubeの利用規約はこちらをご確認ください。
  • 本サービスの認証を通じて取得したGoogleアカウントのデータ（チャンネル情報、ライブ配信の設定および状態）は、ライブ配信の作成、監視および再接続の目的にのみ利用します。
  • 利用者は、Googleのセキュリティ設定ページ（https://security.google.com/settings/security/permissions）において、本サービスのアカウントへのアクセス権をいつでも取り消すことができます。
  • 同様に、Xの設定（「セキュリティとアカウントアクセス」→「アプリとセッション」）において、本サービスのアクセス権を取り消すことができます。
